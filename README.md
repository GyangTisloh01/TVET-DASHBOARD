📌 Project Overview
This project presents an interactive TVET (Technical and Vocational Education and Training) Dashboard designed to provide a clear overview of applicants, registration status, and the skills selected by applicants.
The dashboard provides a visual summary of the number of applicants, registered and unregistered applicants, and the distribution of applicants across Creative Media and Social Media skills.
It is designed to support data-driven monitoring of applicant registration and skills participation.


📊 Key Performance Indicators
The dashboard contains three main KPIs:
KPI	Value
👥 Total Applicants	123
✅ Total Registered	95
❌ Total Unregistered	28

The KPIs provide an immediate overview of the applicant population and registration status.
Registration Rate
Based on the displayed figures:
Registered Applicants: 95
Total Applicants: 123
The registration rate is approximately 77%.
The unregistered applicant rate is approximately 23%.
🎯 Applicant Skills
The dashboard focuses on two skill areas:
- Creative Media
- Social Media
These skills are analyzed according to applicant registration status.
📈 Applicants by Status and Skills
The Total Applicants by Status and Skills chart provides a breakdown of applicants based on their selected skill and registration status.
Status	Skill	Applicants
Registered	Creative Media	50
Registered	Social Media	45
Unregistered	Creative Media	20
Unregistered	Social Media	8


The chart shows that:
- Creative Media has 50 registered applicants.
- Social Media has 45 registered applicants.
- Creative Media has 20 unregistered applicants.
- Social Media has 8 unregistered applicants.
This visualization makes it possible to compare registration levels across the different skills.
🟢 Applicant Registration Status
The Total Applicants by Status donut chart shows the overall distribution between registered and unregistered applicants.
Status	Applicants	Percentage
Registered	95	77%
Unregistered	28	23%
Total	123	100%


The visualization indicates that registered applicants account for approximately 77% of the total applicants, while approximately 23% remain unregistered.
💻 Applicants by Skills
The Total Applicants by Skills pie chart compares applicants across the two available skill areas.
From the dashboard:
Skill	Percentage
Creative Media	57%
Social Media	43%


Creative Media represents the larger share of applicants shown in the dashboard, while Social Media represents the remaining share.

The TVET Dashboard provides a concise visual representation of applicant participation, registration status, and skill preferences.

This project demonstrates how applicant data can be transformed into an interactive Business Intelligence dashboard that communicates information clearly and supports data-driven decision-making.
